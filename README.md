# Structure-Aware Multimodal Research Paper Assistant

An AI-powered multimodal Retrieval-Augmented Generation (RAG) system that understands the structure of research papers by performing layout analysis, section detection, semantic retrieval, and figure association to answer user queries using Gemini.
